# The Minecraft side: BotwCraft

A renamed, adapted copy of [SkyCraft](https://github.com/chasmlol/SkyCraft) by chasmlol (MIT), revision
`bfcaf178524b92c2cdeb88e4ce0f13ef9ded6f32`, adapted for *Breath of the Wild*.

- `fabric/` is the Fabric mod (Minecraft: Java Edition 26.3, Java 25).
- `protocol/botwcraft_protocol.h` is the shared memory's layout, used by the mod and by the bridge's DLL.
- `LICENSE` and `THIRD-PARTY-NOTICES.md` are SkyCraft's and are kept as they came.

What the mod does and what was changed: [docs/minecraft-mod.md](../../docs/minecraft-mod.md).
How to build it: [docs/building.md](../../docs/building.md).
